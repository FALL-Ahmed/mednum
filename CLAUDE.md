# MedNum — Instructions Claude

## Règle absolue : GIT PUSH

**Ne jamais faire `git push` sans que l'utilisateur dise explicitement "push".**

Faire les commits normalement, mais s'arrêter avant le push et attendre la confirmation.

## Messages de commit

Écrire des messages de commit simples et humains, en français. **Ne jamais ajouter** `Co-Authored-By:`, `noreply@anthropic.com` ou toute signature Claude. Juste quelques phrases claires qui décrivent ce qui a changé.
